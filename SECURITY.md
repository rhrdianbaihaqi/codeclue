# Security

`codeclue` only reads files; it never writes, executes project code, or makes network calls.
It does run `git ls-files` (read-only) inside the directory you point `survey` at.

Please report vulnerabilities privately through GitHub:
**Security -> Report a vulnerability** on https://github.com/rhrdianbaihaqi/codeclue.
Do not open a public issue for security problems.
